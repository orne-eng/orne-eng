
# Data Professional Landscape Dashboard

## Overview
I built this interactive dashboard in Power BI using survey data from data professionals around the world. The goal was to clean up a messy, real-world survey dataset and turn it into a clear visual breakdown of salaries, preferred programming languages, career transition difficulty, and overall job satisfaction across different data roles.

## What I Did
* **Data Cleaning & Transformation (Power Query):** Standardized inconsistent job titles, grouped scattered country responses, parsed salary ranges into numeric averages, and filtered out incomplete survey entries so the metrics wouldn't get skewed.
* **Data Modeling & Metrics:** Built dynamic KPI cards and cross-filtering visuals to compare average compensation by role (Data Scientist, Data Engineer, Data Analyst, etc.) alongside work-life balance and salary satisfaction ratings.
* **Visual Design:** Kept the layout clean and easy to scan so anyone looking to enter or benchmark the data field can quickly spot which roles pay the most, which tools dominate, and how hard it is to break into the industry.
